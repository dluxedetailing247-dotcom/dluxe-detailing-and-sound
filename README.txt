D-LUXE PLATFORM v3
1. Configure Supabase in the admin app.
2. Create your admin user in Supabase Authentication.
3. Run supabase-security.sql.
4. Copy public-config.example.json to public-config.json and enter only your Project URL and publishable/anon key.
5. Upload to GitHub and enable GitHub Pages.
Never expose a database password or service-role key.
